# Motion Mirage Finance

A lightweight private finance and invoice management application for Motion Mirage Studios built with Next.js, TypeScript, and Tailwind CSS.

## Included in this starter implementation

- Dashboard overview with key financial metrics
- Client, project, invoice, payment, and expense pages
- Business profile settings
- Data model ready for PostgreSQL and Prisma integration
- Vercel-friendly structure for deployment

## Scripts

```bash
npm run dev
npm run build
npm run start
```

## Stack

- Next.js 16 App Router
- TypeScript
- Tailwind CSS
- Prisma-ready data layer

## Notes

This is the Version 1 foundation for the full Motion Mirage Studios finance system. The app intentionally keeps the invoice template fixed and uses mock data for the first working build while the full database and payment flows are added.
